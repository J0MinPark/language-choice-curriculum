# 전문 대조 기록 — 2026-09-16

초록만의 대조를 대체한다. 아래 범위의 본문과 관련 부록을 읽었다. 모든 관련 논문의 모든 부록을 전수 검토했다는 뜻은 아니다.

| 원문 | 확인 범위 | 초안에 반영한 구분 |
|---|---|---|
| [M’hamdi et al., ACL 2023](https://aclanthology.org/2023.acl-long.217.pdf) | 본문 §§1–6·제한, 부록 C.1–C.3 및 E의 seed 분석 | MTOP 분류·슬롯 과제의 순서 비교와 데이터 양 균등 통제가 이미 존재한다. 신규성을 단순 순서 효과에 두지 않는다. |
| [Marchisio et al., EMNLP 2024](https://aclanthology.org/2024.emnlp-main.380.pdf) | §2.2, §§4.1–4.5, Table A18 | 언어 준수와 등록 정답 일치는 다른 지표다. REQUESTED 실패는 능력 부재만을 뜻하지 않는다. |
| [Sclar et al., ICLR 2024](https://arxiv.org/pdf/2310.11324) | §3의 형식 동등성·FORMATSPREAD 정의 | 문구 민감도 자체를 새 발견으로 주장하지 않는다. |
| [Hua et al., EMNLP 2025](https://aclanthology.org/2025.emnlp-main.1006.pdf) | §§2–3, Tables 1–2 | 모델 간 순위 안정성과 우리 개념 간 순위 안정성은 다르다. 의미적 채점은 등록 문자열 Q를 그대로 대체하지 못한다. |

M’hamdi의 Table 5는 데이터 양을 통제한 비교이므로 우리 단일 역순 실험보다 해당 대안 설명에 대한 통제가 강하다. 그 결과를 우리 설정의 인과적 증명으로 전용하지 않는다. 원문 PDF와 추출 텍스트는 실험 서버에 보존했다. 이 저장소에서는 위 원문 링크로 제공한다.

Dodge et al. (2020)의 기존 초기화·데이터 순서 인용은 유지했다. 이번 회차에서는 해당 논문의 전문 추가 검토를 하지 않았다.

이번 검토에서 채택한 기여 범위: 소형 모델의 학습된 개념들에서 지정 등록 산출, ANY 조건부 언어 배분, 등록 확률 질량을 함께 보고하고 seed·문구·일정에 따른 변화를 구분한다. 최초성·일반 언어 능력·순수 순서 효과는 주장하지 않는다.
