# 의미·어원 검수의 최소 절차

1. 수집 원본의 target_code/sense_order와 snapshot hash를 확인한다. EN/ZH/FR 요청이 동일 KO 의미에 연결되는지 비교한다.
2. 번역 표현이 명사 이름인지, 긴 정의/설명인지, 서로 다른 sense를 나열한 것인지 검토한다. 각 언어 등록표현1개를 해당 sense에서 고르고 원문 대안은 보존한다.
3. KO/EN/ZH/FR 정의가 같은 개념을 가리키는지와 정답 그대로 복사 가능 여부를 검사한다. 중국어 형태·표기와 프랑스어 악센트/관사는 원문과 대조한다. 기계적 삭제로 뜻을 바꾸지 않는다.
4. 동일표현의 여러 언어membership을 유지한다. 언어별로 다른 표기로 강제 변형하거나, 같은표현을 중복확률로 더하지 않는다.
5. EN–FR 각각의 원사전 어원/차용 경로를 해당 의미와 연결한다. evidence URL+스냅샷 hash+검토 범위+결정 이유를 남긴다. 에이전트의 어원 설명만으로 확인 사실로 승인하지 않는다.
6. 어원정보미확인은UNRESOLVED. DISTINCT는 검토 범위에서 별도의 경로라는 뜻이며 모든 역사에서무관하다는증명이아니다.
7. corpus와 결과를 보기 전에 concept/etym family/synonym cluster 및 분석 코호트를동결한다. 출처와어원이관측되지않는집단도coverage에남긴다.
8. 직접 검수한 연구자가 reviewer/review_date를 채운다. 에이전트는 PENDING표를 준비할수있지만 인간승인란을대리서명하지않는다.

`templates/*.example.json`은 필드 설명용이며 실제 데이터가 아니다. synthetic_fixture=true를 지워 학습자료로 위장하지 않는다.

검수 종료는 완전무오류 보장이 아니다. 원문 증거와 판단을 공개해 재검토 가능하게 만드는 절차다.
