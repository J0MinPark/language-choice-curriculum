- ANY/Q 후속 분석과 역순 학습은 이 검사 결과와 별도 실행 계약 검토 후 결정한다.

### 미등록률과 해석 차단 (Qwen 출력 확인 전 추가)

- A의 분모는 모든 60개이며 미등록/빈 출력을 삭제하지 않는다. 미등록은 등록 정답 성공이 아니지만, 요청 언어 실패 C로 분류하지 않는다. C는 다른 언어의 등록 정답 출력만 센다.
- 각 셀에서 A, C, UNREGISTERED, EMPTY의 건수/비율을 별도 보고한다. 공유 membership에 요청 언어가 포함되면 A, 아니면 C이며 이 네 범주는 분모를 분할한다.
- 사전 운영 규칙: 어느 입력×요청×wrapper 셀에서든 (UNREGISTERED+EMPTY)/60 > 10% (7개 이상)이면 `BLOCKED_OUTPUT_VALIDITY`. 이는 보편적 통계 기준이 아닌 이번 탐색의 보수적 설계값이다.
- 이때도 A_robust 수치는 등록 명명 과제의 관측값으로 보존하되, 언어 제어 능력의 결론이나 후속 자동 진행 근거로 사용하지 않는다. 해당 출력을 전수 눈검수하여 설명문/형식, 미등록 동의어, 다른 개념, 불명확을 진단한다. 사후 정답 확장·출력 추출 규칙 변경으로 본 점수를 구제하지 않는다.
- 60개는 개념 수이며 전체 출력은 1,920개이다. 미등록 전수 검토량은 실제 출력 수로 보고한다. 문턱 이하도 타당성의 증명은 아니다.

## 언어 쌍 행렬

조건·입력 언어·wrapper별로 요청 언어 × 등록 정답 출력 언어의 건수와 비율을 기록한다.
한 출력이 여러 언어의 정답이면 SHARED로 분리하고, 미등록·빈 출력도 별도 열로 둔다.
미등록 출력의 실제 언어를 정답 membership만으로 추정하지 않는다. 행 합은 항상 전체 분모와 같아야 한다.
