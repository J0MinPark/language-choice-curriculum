# 능력·선택 궤적 독립 seed 반복 — 결과 이후 탐색 revision

2026-09-16 사용자 요청: 먼저 독립 seed 1회 비용을 측정하고, 기존 예산에서
2~3개 seed를 추가한다. 역순 1회는 정순 비용·공간 확인 후 별도 동결한다.

원래 파일럿의 readiness/measurement 실패는 그대로 보존한다. 이번 질문은
S의 능력·선택 궤적 재현성이므로 실패 자체도 결과로 보고하고 다음 seed를
막는 기준으로 사용하지 않는다. 원래 H/B36와 본시험은 계속 비활성이다.
원본 spec과 이미 출판한 freeze를 변경하지 않는다.

- 고정 seed 4102, 4103, 4104, 순서대로 실행; 성공 seed만 골라 보고하지 않는다.
- 각 seed는 random INIT부터 다시 시작한다. 토크나이저·코퍼스·60개 개념은 공유,
  모델/optimizer/T0는 공유하지 않는다. 기존 4101과 초기 모델 fingerprint를 대조한다.
- 기존 정순 KO→EN→ZH→FR, 기존 학습 recipe·손실·문구·노출 비율을 그대로 쓴다.
  코퍼스 245 + T0/T1/T2/T3 각 3000 = 12,245 업데이트/독립 seed.
  9000은 T0 이후의 T1~T3 구간만이다.
- 기존 200업데이트 간격 평가 및 고정 단계 종점을 유지한다. 데이터로 종료점 선택 금지.
- 먼저 4102:T3:3000에서 운영상 정지하고 실제 원장의 GPU시간을 측정한다.
  학습·평가·저장 비용을 모두 포함한 계상 시간과 벽시계를 구분한다.
- 후속 seed는 남은 GPU시간이 max(2.5h, 첫 seed 실측의 1.5배) 이상일 때만 진입한다.
  24h 캠페인/6h root 상한과 기존 사용량을 유지한다. GPU2만 사용한다.
- root 시작 시 4GiB 예상 산출물 + 5GiB 비상 공간 확인; 매 체크포인트도 기존
  공간 검사를 수행한다. 공간 부족이면 원자료를 지우거나 불완전 실행을 완료로 표시하지 않는다.
- 새 root 결과는 기존 두 문구 점수와 단계 종점 8문구 Q/Z를 같은 조건으로 비교한다.
  단일 seed 재현이나 3~4개 seed만으로 출판 가능성·인과효과를 확정하지 않는다.

실행 이름: `choice-trajectory-independent-seeds-v1`. 역순은 이번 정순 freeze에
포함하지 않으며, 초기 상태를 맞춘 비교 설계와 실제 공간·비용을 확인한 뒤 실행한다.
