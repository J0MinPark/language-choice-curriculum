# 형식 요인 균형과 최악 분할을 적용한 Q 측정 개정 v2

사용자의 현재 개정 요청에 따른 후속 탐색 규칙이다. 8문구 실행 결과를 본 뒤 작성한
개정임을 명시한다. 원본 spec/, 기존 freeze와 과거 판정을 소급 수정하지 않는다.
새 본시험·H 실행 권한을 부여하지 않으며 main_enabled=false를 유지한다.

## 측정 대상과 요인

동일 개념·모델·입력언어에서 고정한 8개 문구의 정규화 Q를 동일 가중치로 평균한다.
원시 p를 합친 뒤 정규화하거나 Z에 따라 가중/선택하지 않는다.
- header: 뜻풀이 / 정의 (각 4회)
- answer_label: 표현 / 한 줄 답 / 답 / 응답 (각 2회)
- 2×4 전요인 조합을 정확히 한 번씩 포함한다.
- 정의 내용, 입력언어, 개행·콜론 형식은 고정한다. 특히 최종 콜론 뒤 공백·개행 없음.
새 형식 축을 추가하면 수준, 조합 및 가중치를 새 실행 전에 명시하고 균형 구성한다.
균형은 평균 측정 집합의 구성 조건이다. 모든 스트레스 분할도 균형이어야 한다는 뜻이 아니다.

## 판정: 최악 분할을 주보고

8개를 4+4로 나누는 고정된 35개 비중복 상보 분할을 모두 사용한다.
뜻풀이 4개 대 정의 4개 분할 및 답변 라벨 두 수준 대 두 수준 분할도 포함한다.
각 언어별로 모든 분할의 최소 Spearman, 최대 평균 절대차 및 해당 분할 ID를 보고한다.
단일 분할의 평균, 28/35와 같은 통과 비율, 유리한 분할로 최악 실패를 대체하지 않는다.

통과 조건은 전부 충족해야 한다.
1. 각 문구의 Z 중앙값≥.90, Z<.05인 개념 비율<.10.
2. 모든 분할·모든 언어의 rho≥.60. undefined도 실패.
3. 모든 분할·모든 언어의 평균 |Q_left−Q_right|≤.15.

기존 사전 균형 분할은 설명용 보조분석으로 보존한다. 문구 평균이 한 분할에서
안정적이어도 최악 분할 미달이면 BLOCKED_WORST_SPLIT_MEASUREMENT이다.
하나라도 Z 조건이 실패하면 BLOCKED_HIGH_Z이다. 두 실패가 공존하면 둘 다 기록한다.
낮은 Z 문구·개념 삭제, 사후 문구 교체, 임계값 완화는 하지 않는다.
35개 분할은 독립 반복이 아니다. 최저치는 이 유한 집합에서 관측한 최저치이며
모든 새 문구/새 root에 대한 통계적 하한이나 보장은 아니다.

## 현 결과 재판정

prompt_average_probe_v1의 이미 관측된 데이터에 v2를 적용한 결과를 별도 JSON에 저장한다.
이를 새 자료에서 전향적으로 검증한 결과로 부르지 않는다. 현 4080 checkpoint는
높은 Z 조건을 충족하지만 최악 분할 상관이 KO .465 / EN .557 / ZH .429 / FR .546으로
미달이다. 원본의 PRIMARY_MEAN_STABILITY_SUPPORTED 기록은 보존하되 v2 통과로 쓰지 않는다.

## 인접 체크포인트 변화 진단

남아 있는 정순 T0→T1→T2→T3 및 계보가 확인된 탐색 연속학습
T3→prompt_mix_3360→lower_lr_3720→lower_lr_4080을 같은 8문구로 측정한다.
두 경로는 보고에서 구분한다. 전자는 단계당 3000업데이트와 새 언어 도입이 결합되고,
후자는 360업데이트 간격이지만 학습률/문구 혼합 변경과 dev 기반 선택이 포함된다.
서로 다른 arm을 시간상 이웃이라는 이유로 연결하지 않는다.

각 인접 쌍에서 개념·언어별 평균 Q의 signed 변화와 절대 변화, 벡터 TV를 보고한다.
각 시점의 문구 변동과 같은 단위로 비교한다. 동일 분할의 변화량을 양 절반에서 구한
차이(Delta_left−Delta_right)도 35개 모두 보고해 변화 자체의 형식 민감도를 확인한다.
낮은 Z/최악 분할 미달은 숨기지 않는다. 평가용 후보집합은 모든 시점에서 4언어 고정이다.

이 변화는 ΔH(A/B 이력 대조)가 아니고 ΔH의 하한도 아니다. 예시수·시간간격·신규언어·
학습률이 다른 변화량을 .03/.2 경계로 본시험 검정력으로 환산하지 않는다.
같은 문구를 짝지은 변화에서 형식 효과가 상쇄될 수 있으므로 단일 모델의 문구 차이는
그대로 ΔH의 독립 가산 잡음이나 확정적 noise floor가 아니다.
큰 변화는 이 모델이 학습에 반응할 수 있다는 근거일 뿐 H 효과/검출 가능성 보장이 아니다.
작은 변화도 모든 H 일정의 효과 부재를 입증하지 않는다.

GPU2 읽기 전용, 신규 학습 0, 기존 24 GPU시간 원장, 이번 예약 상한 1200초.
4080의 같은 8문구 점수는 해시 검증 후 재사용한다. 실제 새 GPU 평가는 6개 체크포인트이다.
추가 예산 없음. 이번에 체크포인트를 더 삭제하지 않는다.
