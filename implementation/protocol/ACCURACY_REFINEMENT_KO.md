# 추가 정확도 개선 비교 v2

사용자의 추가 방법 시도 요청에 따라 이전 prompt_mix 종점(3360회)을
모든 조건의 공통 full-state 출발점으로 삼는다. 단일 root의 dev 결과를
이미 본 뒤의 탐색이며 독립적인 확인 실험으로 보고하지 않는다.
원자료, 승인 코호트 60개, 정답 및 평가 문구와 임계값은 변경하지 않는다.

각 조건은 정확히 360회(11,520 예시)를 추가한다. 최종 phase step은 3720이다.

- constant: 기존 개선안 그대로 LR 1e-4, KO 지시문 약 절반 변형.
- lower_lr: LR만 3e-5로 감소.
- balanced_cells: LR 1e-4 유지, 각 개념×target×input×mode×wrapper를
  두 번의 완전 Cartesian cycle로 배치. 전체 노출 비율은 같지만
  개념별 세부 조건 배치와 예시 순서는 대조군과 달라진다.
- full_prompt_mix: LR 1e-4 유지, KO 지시문 변형 비율만 약 절반에서 전체로.

새 후보 선정 기준은 실행 전 새 동결에 기록한다. readiness 모든 셀 통과,
중국어 합산 정답이 출발점 대비 2/120 이상 및 대조군 대비 1/120 이상 개선,
프랑스어 합산은 출발점보다 하락하지 않고 대조군 대비 최대 1/120 하락 허용,
한국어·영어 각 셀은 출발점과 대조군 대비 최대 1/60 하락만 허용한다.
이 기준은 다음 탐색 후보 선택용이며 기존 연구의 measurement gate를 대신하지 않는다.
test로 설정을 고르지 않고, 점수가 낮은 항목을 데이터에서 버리지 않는다.
H/다른 root/main 또는 추가 학습으로 자동 확대하지 않는다.

사용자의 불필요 데이터 폐기 허용은, 검증된 최종 전체 상태가 따로 남는
실험용 중간 state.pt 정리에만 적용한다. 원자료/주석/각 단계·실험 종점/
점수·추적기록·manifest를 보존하고 삭제 대상 SHA와 사유를 기록한다.
새 실행에서도 180회 디스크 저장·복원을 먼저 검증한 뒤, 360회 종점 평가가
저장됐을 때만 해당 arm의 중간 state.pt를 폐기한다. 삭제된 중간 가중치의
별도 복구본은 없으며 최종 전체 상태가 남는다. 서버의 다른 디스크와 설정은
변경하지 않고 GPU2·기존 누적 예산·5 GiB 비상 공간 규칙을 유지한다.
